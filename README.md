# Ben 10 React Character Gallery

A beginner React project built with Vite. Four Ben 10-inspired character illustrations are displayed using one reusable `Image` component.

## Run in Visual Studio Code

1. Open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Screenshot for your assignment

With the React page running in your browser, press **Windows + Shift + S** and capture the full gallery. Save the screenshot and submit it along with `Ben10_src.zip`.

## Where to look

- `src/Image.jsx` — reusable image component with `source` and `width` props.
- `src/App.jsx` — imports the image component and displays four characters.
- `src/assets/` — four local illustration files.
- `src/App.css` — simple responsive gallery styling.

The separate `Ben10_src.zip` file contains just the `src` folder for the class submission.
